# 大学路街道智能体交互推演 Implementation Plan

Goal: 从提供的 3dm 制作有尺寸依据的技术总平面与本地 HTML 智能体推演，比较索网布置和装置数量。

Architecture: 用 rhino3dm 提取真实场地几何并转为米；独立 JS 引擎负责图上路由、需求识别、分配、状态机和覆盖/响应指标；Canvas 绘制、表单与指针交互负责浏览。最终打包一个无需外部依赖的 HTML。

Scope: 设计研究工具，全部在本机，不发布或上传模型。原 3dm 不改动。模型未提供真实气象、流量标定、供热性能、结构承载或朝北信息；不虚构这些数据。

Assumptions: 道路平日/市集两种模式；平日软机器人不进入车行道，市集允许进入。上空索网是候选几何中心线，工程净高与锚固尚需验证。热光圈沿一维网络运动，不虚构任意平面飞行。跨索转接机构是待深化设计条件。全局最优不作承诺。

## Tasks
- [x] 1 提取场地：建筑剖投影/轮廓、道路与人行道网格边界、树冠/树干近似、市政及外摆占地；输出 model.js 和来源尺寸记录。
- [x] 2 先写引擎行为测试并观察失败：索网最短路与响应时间、平日道路禁入、供热容量与功率约束、机器人路径避障和占用后停稳、空需求、单装置不重复分配、数量/范围变更。
- [x] 3 实现引擎：比较两纵轨/横跨梯架/组合索网；公平采样覆盖与响应；需求聚类、停留阈值、优先级、排队、热圈分配及机器人展开/服务/收拢；参数均有单位。
- [x] 4 实现技术图纸风格的本地页面：尺寸线、图例、图层、缩放平移、拖人/放人/目标点、点击请求休息、状态和轨迹、参数与布局比较、设计过程、数据导出与平面 PNG 导出。
- [x] 5 验证：Node 行为测试、模型校核、实际浏览器操作与截图；输出独立 HTML、技术平面 PNG、设计说明和可复算结果。

## Review focus
道路模式变化时禁止机器人抄近路穿车行道；不能到达或网络不相连时显示未覆盖；热圈的功率/人数不与可视圆圈混为一谈；服务中机器人不带人移动；屏幕变化与缩放不使拖动坐标偏移。

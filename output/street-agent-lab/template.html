01 / 从真实空间提取约束

主车行道宽 12.413 m；树干、树池、外摆与设施划为地面障碍。树冠仅为投影参考，轨道与树冠重叠处需进一步检查立体净高。

02 / 比较覆盖与资源，而非先铺满索网

双侧纵轨作基线；中央纵轨＋横跨支路服务马路；三纵轨横跨网增加覆盖。所有方案以相同 2 m 网格采样，比较中心线长度、端点支撑数和静态响应时间。

03 / 两套智能体共享需求图

独行与结伴行人持续行走，社交意愿影响偶遇概率、停留时长和热点选择。达到停留阈值才形成热需求；主动休息、疲惫/酒后或高社交人群优先进入分配。毛毛虫在多人、休息需求或高社交停留点附近寻找可展开位置。

04 / 单人—多人—闲置形成闭环

热圈：待机 → 沿轨移动 → 定点供热 → 需求消失后待机。毛毛虫：压缩待机 → 避障前往 → 停稳展开 → 有人使用时锁定位置 → 无人 12 秒后收拢返回。

05 / 让三个人各自有可设计、可计算的对象

A：悬索、热圈与调度；B：软体变形、伸缩底盘与地面可达；C：人因交互、压力发光、MR 实验与评价。共用同一坐标、需求识别和日志。

这是任务书“感知—计算—反馈”的平面验证底座。热舒适、风场、索力、树冠净高与结构承载仍需下一轮专项求解；当前不把灯光范围称为舒适保证。
筛选目标

每种布局测试 3 / 5 / 7 / 9 / 11 个站点、3–8 个光圈；先满足目标，再按轨道中心线长度和光圈数排列。有限枚举，不代表全局最优；P95 仅统计可达采样点，不含排队和需求识别时间。

需求、人群与交互

需求 = 停留 ≥ τ 或主动请求休息
群体 = 距离 ≤ r 的邻近聚类
优先级 = 100u + 个体需求 + 3n + 等待/30 + 10k_sS̄

接触与压力发光以服务状态和主动操作表示；平面图不求解膜体受压形变。独行者偶遇停留是可复现的概率行为模型，非真实观测结论。社交意愿 S 是手动或随机情景参数，用于表达“愿意停下来与人共处”的倾向，不用于推断真实性格或心理状态。

容量与能耗代理

可服务人数 = min(Nmax, ⌊P × η / q⌋)
耗电 Wh = Σ 功率 W × Δt / 3600

P、η、q 均为可改的假设。服务半径为几何筛选参数，不能替代辐射视角系数、人体吸收率与实测热舒适。软体移动/充气/待机暂取 90/140/12 W。

移动与覆盖

热圈时间 = 图最短路 / v + 转接估时
机器人路径 = 0.6 m 网格 A*
可行区域 = 公共铺装 − 障碍物 − 安全余量

收拢态避障半径暂设 0.55 m；展开用半径 2.65 m 的完整保守包络及周边采样校核。开口朝向为示意，尚未用完整变形轮廓校核。平日禁入车行道，步行化允许进入。

环境反馈与机器人协同

可切换空气温度、辐射温度 MRT、体感温度和风速场。建筑背风、弧幕与低位软体挡风采用指数衰减代理，供热以辐射通量换算 MRT，空气为局部混合升温。这是未标定的场景模型，不是 CFD 或人体生理预测。体表温度、精神状态和社交意愿影响需求权重、停留阈值、偶遇停留与装置吸引。完整公式见“计算逻辑”页。

温度场为什么以前几乎同色：原空气图把 6–6.7℃ 映射到整条色带，而 1.8 kW 光圈中心只让空气升约 0.06℃；MRT 圈心实际约 +4.7℃，原图却按 +10℃ 着色，只用到半条色带。若某一刻热圈都在沿轨移动（供热中 0/5），整张图就是背景值。现在空气按 0–1.6 K 局部混合代理、MRT 按 0–4.5 K 着色，并增加体感温度场与“全圈供热预演”；预演会同步重着色行人体感，但不改变调度，不是实时状态。右上角热场详图放大 24×14 m。

机器人按避障路径时间选择最近空闲者，接单后预留服务区，8 m 内不重复派单；需求散去释放预留。下一步导入真实 CFD / 辐射计算场。

轨道中心线不是完整受力索网，实际索材还包括成对承载索、支索、锚固与供电；转弯、跨轨转接与多人多环避碰仍需机电设计。

1 个体与体感

C = clamp( (32.5 − T_skin)/4 + max(0, 12 − T_air)/16 + v/6 − max(0, MRT − T_air)/12, 0, 4 )
τ = max(1, dwell / (1 + 0.3C))
F = 0.58T_air + 0.42MRT − 1.15v^0.8 + 0.7(w − 1.15) + 0.3(T_skin − 32.5) + m

m：平稳 0 / 紧张 −0.25 / 疲惫 −0.5 / 酒后 −0.8。F 是体感代理，只用于着色和比较。

2 社交意愿 S

S ∈ [0, 1]
p_meet = 0.20 · (0.25 + 1.5 S̄) · Δt
p_hotspot = 0.25 + 0.50 S
T_meet = 10 + 20 S̄ + U(0, 15) s

S 越高，越容易停下来交谈、停留更久、更倾向走向热点位置；S 不是心理诊断。

3 需求与群体

需求条件：rest ∨ urgent ∨ stay ≥ τ
群体：d_ij ≤ r 的人聚为一组
S̄ = (1/n) Σ S_i
P_d = 100u + max(P_i) + 3n + stay_max/30 + 10k_sS̄

u=1 表示组内有主动休息、疲惫或酒后需求；P_i 为个体需求权重。

4 热光圈

t_H = L_H / v_H + n_turn · t_transfer
派单：任务按优先级排序 → 每个任务选最近空闲圈
N = min(N_max, ⌊P · η / q⌋)

L_H 为轨道最短路；n_turn 为转接次数；t_transfer=1 s。热圈之间按 2×heatRadius 服务区和 3.4 m 机体间距互斥，两个供热圈不会重叠；k_s 只影响任务优先级，不再改变距离成本。状态：待机 → 沿轨 → 转接 → 定点供热 → 待机。

5 毛毛虫

t_R = L_A* / v_R
cost_R = t_R − 10 · k_s · S̄
出动条件：urgent ∨ n ≥ 3 ∨ (k_s > 0 ∧ S̄ ≥ 0.80)

L_A* 为 0.6 m 网格 A* 路径长度。状态：压缩待机 → 避障前往 → 停稳展开 → 服务 → 收拢返回。接单后预留 8 m 服务区；无人 12 s 后收拢，展开约 6 s。

6 环境场

Φ = Σ P · η / (2πr²) · dz/r
MRT = ((T_bg + 273.15)^4 + Φ/(0.95σ))^0.25 − 273.15
T_air = T_bg + Σ (P/1800) · 2.4 · e^(−d²/5) / (1 + 0.4v_bg)

v 由建筑背风、软体挡风和热圈扰动修正；σ=5.670×10⁻⁸。指标：E = ΣP·Δt/3600；覆盖 = 可达样本/总样本；P95 = 响应时间 95 分位。所有场为缩减模型，不是 CFD。

符号与约束
T_skin 体表温度；T_air 空气温度；MRT 平均辐射温度；v 风速；w 期望步速；S 社交意愿；S̄ 群体平均社交意愿；n 人数；u 紧急标记；P 功率；η 有效供热比例；q 单人需求；k_s 社交吸引权重。固定常数：socialRobotMin=0.80，毛毛虫服务区 8 m，热圈服务区 2×heatRadius。k_s=0 时关闭社交优先级、毛毛虫派单加成与高社交独行者出动。公式与代码一一对应；系数是待标定假设，完整说明见 README 与“温度场诊断与修正”。
